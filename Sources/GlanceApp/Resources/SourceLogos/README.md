Place bundled source logo files in this folder.

Supported filenames today:

- `opencode.pdf` or `opencode.png`
- `claude-code.pdf` or `claude-code.png`

SwiftPM processes this directory into the GlanceApp bundle.

When no matching file exists, Glance falls back to the current SF Symbol for that source.

Current bundled assets in this repo:

- `opencode.png`
- `claude-code.png`

Antigravity and Devin CLI use SF Symbols; no Gemini CLI logo is bundled.
